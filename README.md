# lab.fresthomes.com

Internal workspace of Frest Homes (brand, library, materials, AI studio, backlog). AES-GCM encrypted pages; registered e-mail + passcode (PBKDF2-SHA256 300k, per-person wrapped keys). Add/revoke: `lab/data/users.json`, rebuild, upload. Drive folders are embedded by ID from `lab/data/drive.json` (info@frest.lv drive only). Generator in Drive `WEB/gates/`.
